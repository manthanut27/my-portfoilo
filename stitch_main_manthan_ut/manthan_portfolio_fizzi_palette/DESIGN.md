# Manthan Utekar Portfolio Design System

## Brand Identity
A vibrant, creative portfolio for a fresher full-stack developer. The design should feel energetic, youthful, and technically impressive.

## Color Palette ("Fizzi")
- **Fizzi Yellow (Primary BG)**: #FDE047 — Hero section background
- **Orange-Red (Accent)**: #FE6334 — CTAs, active states, badges, marquee bg
- **Navy (Text)**: #0c4a6e — Primary text color, headings
- **Lime**: #D9F99D — About section background
- **Cyan**: #C0F0F5 — Skills section background
- **Pink**: #FFA6B5 — Projects section background
- **Lavender**: #E9CFF6 — Terminal section background
- **Green**: #CBEF9A — Contact section background
- **Grape**: #572981 — Eva Bloom project accent
- **Cherry**: #710523 — BMW project accent

## Typography
- **Headlines**: Syne, weight 800, navy #0c4a6e
- **Body**: Inter, weight 400-500
- **Labels/Code**: Space Mono, monospaced
- **Section titles**: 74px+ all-caps
- **Name reveal**: Very large display type (100px+)

## Design Principles
1. Each section has a distinct vibrant background color
2. Frosted glass/glassmorphism for cards and stat blocks
3. Smooth transitions between sections with kanji characters
4. Marquee strips between sections (orange-red bg, yellow text)
5. Bold, oversized typography for impact
6. Generous whitespace within sections
7. Playful decorative elements (floating blobs, spinning rings)

## Component Styles
- **Buttons**: Rounded, solid fills, bold text, hover scale effects
- **Cards**: Frosted glass (backdrop-blur), subtle borders, perspective hover transforms
- **Badges**: Small pill shapes with status-indicating colors
- **Forms**: Clean inputs with frosted glass container
- **Navigation**: Fixed top with backdrop blur, scroll progress bar

## Layout
- Full-viewport sections stacked vertically
- Marquee strips as visual dividers
- Horizontal scroll for projects
- Responsive: Desktop (full experience) → Mobile (CSS fallbacks)
